EMBERLINE — a round-based tactical FPS in three.js. One attacker, five Ashen defenders, and a spike to plant at site A or B in a dusk industrial yard: earn money each round, buy rifles, an SMG, a scoped DMR, grenades and plating, and win rounds by elimination, detonation or defusal.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
